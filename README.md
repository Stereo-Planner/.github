# Stereo-Planner

**Learning Stereo-to-Trajectory Planning for Zero-Shot Sim-to-Real Quadrotor Navigation**

</div>

## 👋 About

Stereo-Planner is an end-to-end vision-to-action framework, built on ROS 2, for agile and collision-free quadrotor flight.
We will open-source **everything needed to train, deploy, and fly Stereo-Planner on a real drone**:

| Component | Description |
| :-- | :-- |
| [**Stereo-Planner**](https://github.com/Stereo-Planner/Stereo-Planner) | Stereo-Planner algorithm for training, deployment, and online inference |
| Simulator | Unity-based simulation environment with plug-and-play scene construction using assets from the Unity Asset Store |
| Hardware | Drone design and SOLIDWORKS CAD files, plus a purchase list of all components needed to build the drone |
| Stereo VIO | Stereo visual-inertial odometry for aggressive real-world flight |
| Drivers | Drivers for the onboard sensors |
